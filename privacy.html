Privacy Policy

Last updated: September 9, 2026.

Boss Brain Backup is a private, single-user backup utility. It is not offered as a public service.

Google Drive access

The application requests the Google Drive drive.file scope. This is used to create, read, verify, and manage backup files created through the application. The application does not request broad access to pre-existing personal Google Drive content.

Backup data

Backup content and file names are encrypted on the user's computer before upload. OAuth credentials and encryption secrets are stored locally and are not published on this website.

Data sharing

No Google user data is sold, used for advertising, or shared with third parties by this application.

Website data

This website contains no analytics, advertising, cookies, or tracking scripts added by the application owner.
