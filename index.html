Boss Brain Backup

Boss Brain Backup is a private, single-user backup utility used to create encrypted off-site backups to Google Drive.

The application requests the Google Drive drive.file scope so it can access only files and folders created or opened through the application. It does not request broad access to existing personal Drive content.

No analytics, advertising, or tracking scripts are used on this site.
